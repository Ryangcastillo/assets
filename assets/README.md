# Assets Directory

This directory contains all static assets organized by type.

## Structure

- **images/**: All image files (PNG, JPG, SVG, etc.)
  - Organize by project or category
  - Use descriptive filenames
  - Include alt text in documentation

- **icons/**: Icon files and icon sets
  - SVG format preferred for scalability
  - Organize by style or theme

- **videos/**: Video files and media
  - Include multiple formats when possible
  - Add captions/subtitles when applicable

- **audio/**: Audio files and sound assets
  - Include different quality versions
  - Document usage rights and attribution

- **documents/**: PDFs, docs, and other document files
  - Version control important documents
  - Include metadata and descriptions

## Naming Conventions

- Use kebab-case for filenames: `my-awesome-image.png`
- Include version numbers when applicable: `logo-v2.svg`
- Use semantic names: `hero-background.jpg` instead of `img001.jpg`

## File Size Guidelines

- Optimize images for web use
- Keep individual files under 10MB when possible
- Use appropriate compression without sacrificing quality
